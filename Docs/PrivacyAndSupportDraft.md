## Privacy Policy

**Effective date:** {{EFFECTIVE_DATE}}

{{PUBLIC_APP_NAME}} is a local-first learning application provided by
{{DEVELOPER_NAME}}.

### Data storage

Learning preferences, responses, progress, review schedules, saved actions, and
settings are stored locally on the device. The app does not require an account and
does not send this learning data to the developer or to a backend service.

### Data collection and tracking

The current version does not include advertising, analytics, tracking, crash
reporting, or third-party data-collection SDKs. The developer does not collect data
from the app.

### User-initiated sharing and links

If a person chooses the system Share action, iOS sends the selected progress text
only to the destination they choose. Opening a source link leaves the app and is
then governed by the destination website's privacy practices.

### Deleting data

Learning progress can be deleted from Profile → Reset Learning Progress. Deleting
the app also removes its local data, subject to the device's own backup and restore
behavior.

### Changes

This policy will be updated before the app adds any account, synchronization,
analytics, advertising, or remote service that changes its data practices.

## Support Page

### Contact

Email: {{SUPPORT_EMAIL}}

When reporting a problem, include the app version, iOS version, device model, the
screen where the issue occurred, and steps to reproduce it. Do not send private
learning responses unless they are necessary to reproduce the issue.

### Common actions

- **Start over:** Profile → Reset Learning Progress.
- **Change session size:** Profile → Practice → Session Size.
- **Change appearance:** Profile → Appearance.
- **Share progress:** Profile → Share a Progress Snapshot.
- **No connection:** the core learning loop is designed to work offline.

### Data recovery

The current version has no account or cloud synchronization. If the app is deleted
or the device is lost, the developer cannot recover the locally stored learning
history.
